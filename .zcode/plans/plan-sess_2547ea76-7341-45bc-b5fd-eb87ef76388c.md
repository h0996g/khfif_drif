**Endpoint contract** (swagger/driver.json): request `{"acceptsFemaleOnly": bool}` (JSON body), response is the **flat** `DriverProfileResponse` (id, fullName, gender, phone, email, status, dateOfBirth, preferredLanguage, profileCompleted, kycStatus, acceptsFemaleOnly, vehicleCategory, vehicleTier, vehiclePlate, vehicleModel, activeServiceTypes, isOnline, requiresRekyc). Errors 400/401/403 flow through the existing `DioClient` → `ApiException` path.

### 4. Repository — new `lib/features/profile/driver/data/driver_profile_repository.dart`
Mirror `DriverServiceTypesRepository` (`final class`, const constructor, static `DioClient.put`, no try/catch — the cubit catches):
```dart
final class DriverProfileRepository {
  const DriverProfileRepository();

  /// Updates editable profile fields and returns the full updated profile.
  Future<DriverProfileModel> updateProfile({required bool acceptsFemaleOnly}) async {
    final response = await DioClient.put(
      path: DriverApiConstants.profile,
      data: DriverProfileUpdateRequest(acceptsFemaleOnly: acceptsFemaleOnly).toJson(),
    );
    return DriverProfileModel.fromJson(response.data as Map<String, dynamic>);
  }
}
```
Auth header, idempotency key, 401 refresh/retry all come free from `DioClient` interceptors.
