Implement `GET /api/driver/rides/{rideId}` (ride detail) end-to-end, mirroring the ride-history feature's patterns (constant → model → repository → cubit → view → route), with the detail screen reached by tapping a history card.

**Endpoint contract** (swagger/driver.json): path param `rideId` (uuid); 200 → `DriverRideDetailResponse`, 404 "Ride not found". The response is a flat superset of the history item: adds `passengerId`, `passengerPhone`, flat `pickupLat/Lng` + `dropoffLat/Lng`, `arrivedAt`, `startedAt`, `distanceMeters`, `durationSeconds`. State enum reuses the shared `RideOutcome`; 404 surfaces as `ApiException` → failure state.

### 3. Repository — `lib/features/ride/driver/data/driver_ride_repository.dart`
Append after `listHistory`:
```dart
/// Full detail for a single past ride.
Future<DriverRideDetail> getRideDetail(String rideId) async {
  final response = await DioClient.get(
    path: DriverRideApiConstants.detail(rideId),
  );
  return DriverRideDetail.fromJson(response.data as Map<String, dynamic>);
}
```
